# Audit des photographies des standalone publiés — 1er novembre 2026

Le contrôle des douze fiches signalées par l’ancien audit a été refait avec l’inventaire officiel des images de chaque attraction (`ResolveFacebookPublication`, champ `images.pagination.totalItems`). **Huit fiches n’ont aucune image publiée ; une autre, FlyOver America, ne montre que l’enseigne. Trois fiches possèdent déjà une photographie de l’attraction.** L’ancien chiffre de douze fiches sans photo était donc erroné.

Les neuf actions correctives restent dans les JSON nationaux. Leur statut « Integrated » et leur dernière date d’intégration ne changent pas sur la base de ce contrôle en lecture seule. Quand une photo est effectivement importée, sa nouvelle date d’intégration doit être enregistrée sans effacer l’historique ; la publication Facebook existante ne doit pas être rejouée.
