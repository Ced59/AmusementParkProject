# Inventaire européen — registre étendu au monde entier

Le registre permanent est désormais dans [world-integration](../world-integration/README.md). Le résumé mondial conserve une section Europe et les fiches de chaque pays. Les identifiants et historiques de la première étape européenne sont conservés.

Le PDF et l’Excel européens remis pendant la préparation sont une photographie intermédiaire, remplacée par le rapport mondial. Le rapprochement des fiches sans pays renseigné peut corriger leurs compteurs.
