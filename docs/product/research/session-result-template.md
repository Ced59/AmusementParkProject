# Fiche de session produit

> Copier cette fiche par session dans l'espace de recherche à accès restreint.
> Ne pas la committer lorsqu'elle contient une observation réelle, une citation ou
> un contexte susceptible d'identifier une personne.

## Cadre

- Code de session non identifiant :
- Programme : `RANK | PASS | SHARE | FIT | WATCH | TRIP | HIST | LIVE`
- Objectif décidé avant la session :
- Gate étudiée :
- Date :
- Modérateur :
- Profil canonique :
- Appareil, largeur approximative, connexion et mode d'entrée utiles :
- Consentement à l'observation : `oui | non`
- Consentement à une citation courte : `oui | non`
- Enregistrement séparément consenti : `non | oui, rétention et emplacement`

## Clôture
